01 / CAPABILITIES

让演示保持简单。

从录网页作品出发，把录制、现场讲解和本地保存连起来。

01

选定画面，持续录制

完整网页可见区域，或拖动一次框选。没有点击和标注时，动画与声音也继续录制；支持暂停与继续。

02

把讲解放进画面

箭头、方框、画笔、多行文字与点击光圈。鼠标选择、移动、缩放标注，切回「操作网页」继续演示。

SVG 实时标注
03

提前准备好素材

收藏本地参数图、截图和音乐，录制时直接插入图片、调节背景音乐。收起素材区时释放试听与缩略图。

图片素材 / 本地音乐
04

录完回看，自行导出

视频分段保存在本机。按需预览、下载 WebM、支持时直接录制 MP4，或将已有 WebM 转为 MP4。

不自动下载 / 保留原片
网页演示优先

完整网页 / 固定区域

整页采集当前视口；区域框选一次持续使用。标注进入画面，控制侧栏在标签页来源外。区域不跟随网页元素，真实视口变化仍需重选。

基础通用录制

窗口 / 屏幕

系统选择来源，独立页承载、复用录制库。没有桌面级标注，整屏可能录到可见工具窗口；声音依浏览器和系统。

讲解与本机保存

图片、文字、音乐与 MP4

准备本地参数图和音乐，现场讲解；录完回看、手动导出。MP4 取决于运行时支持，转码通常接近视频时长。

03 / DELIVERY STAGES

每一步，都对应具体能力。

按历史工作重点归为六段，并非正式里程碑或功能首次出现的时间。当前代码为 v0.6.9，实机验收仍待完成。

  1. 01 / v0.1.x

    建立录制原型

    网页采集、区域、基础标注与本地保存；完整画面优先直录，约束尺寸和帧率。

  2. 02 / v0.2.x

    打通现场操作

    开始后选范围、文字输入与图形编辑；取消、结束隐藏标注，同页恢复。

  3. 03 / v0.3.0

    让保存可恢复

    沿用片段保存，强化停止兜底、失联恢复和诊断；v0.2.x 已有片段原子写入。自动下载后来撤回。

  4. 04 / v0.4.0–0.4.8

    格式与区域稳定

    MP4、导出保护、固定选区、补边映射、低负载与初步图片标注；录完回看，按需下载。

  5. 05 / v0.4.9–0.6.0

    准备讲解素材

    空闲网页自动连接、备选图片、本地音乐收藏与混音；围绕演示增加少量入口。

  6. 06 / v0.6.1–0.6.9 · 当前

    减少资源浪费

    授权指引、取消超时、长片文件回看、分页重连、长笔迹和侧栏按需加载；实机性能待闭环。

下一步：先交付可复核的真实录制对照。来源、停止和保存优先验收；若复现严重故障立即处理，同时建立侧栏、整页与区域的资源对照，再按瓶颈优化。

区域录制为什么更费资源？

当前先采集来源，再播放到视频元素，通过 Canvas 裁切、输出媒体流后编码。比满足直录条件的整页路径多了逐帧处理；已经限制来源尺寸、跳过重复帧、暂停时停止绘制，实际收益仍需测量。

查看四条处理链路 →

资源占用如何约束？

闲置侧栏不开启采集；素材按需载入；标注历史设预算；大视频按需创建文件预览。取消、超时、停止时释放媒体资源。预算与保护机制不代表 Chrome 进程内存的硬上限。

录制前需要了解的边界
  • 「完整网页」录的是当前视口，滚动后录入新画面，不会一次捕获整个长网页。
  • 选区固定在视口位置，不跟随网页元素。采集容器分辨率变化会重新映射；真实 CSS 视口改变或选区越界仍需要重选。
  • 标注、文字编辑框和选中手柄会进入视频；录完标注收起，同页可恢复，刷新或关闭网页会清空。
  • 网页侧栏在标签页来源外；录整个屏幕可能包含可见控制窗口。实际鹧鸪成片中的工具排除仍待验收。
  • MP4 取决于运行时编码支持。已有 WebM 转 MP4 会解码后重编码，通常接近播放时长，可能改变画质。
  • 本地库不是外部备份；卸载扩展或清除数据可能丢失录制，重要内容请自行保存。

07 / GET STARTED

在 Chrome 中开始。

无需安装依赖或编译。最低 Chrome 116；建议使用当前稳定版，MP4 能力单独检测。

获取项目源码 ↗

已从原目录加载的用户保持该路径，更新后重新加载扩展，并刷新目标网页即可。

  1. 准备目录

    GitHub「Code → Download ZIP」解压，或克隆仓库。找到直接包含 manifest.json 的目录。

  2. 加载扩展

    打开 chrome://extensions，开启「开发者模式」，选择「加载已解压的扩展程序」并选中该目录。

  3. 授权并连接

    打开普通网页，点击映录图标。首次点击「开启自动连接网页」并允许访问；之后正常切换网页会自动识别。录制来源仍受 Chrome 授权限制。

  4. 选好范围再演示

    点击「开始录制」，选择完整网页或框选区域；结束后回看，按需导出。建议先做一段 30 秒短录。
