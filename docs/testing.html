当前结论的边界

已有单元测试与浏览器合成媒体验证；尚未完成安装扩展后对鹧鸪项目的实际录制及 CPU / GPU / 内存对照。下方步骤是测试方案，不是已取得的性能结果。

① Chrome 中的性能对比

保持测试条件相同

  • 打开鹧鸪项目，固定同一种实现、天气、镜头和动画状态。能独立打开示例时，优先使用独立页。
  • 建议先用「高清、30 FPS、WebM」，关闭网页声音、麦克风、背景音乐、点击光圈和性能诊断；图片、音乐区保持收起。
  • 固定浏览器窗口、缩放和侧栏宽度。录制前先等场景加载稳定；不要同时回看、转码、运行其他录屏工具。确认磁盘有空余。
  • 按 Shift + Esc 打开 Chrome 任务管理器，右键表头显示 CPU、内存占用空间和进程 ID。记下鹧鸪网页、映录相关条目以及 GPU Process 的数据。

若侧栏、离屏页、后台出现在多个条目中，应逐行记录 PID，避免漏记；共享进程也不要重复相加。GPU Process 中的 CPU 数字是该进程的 CPU 占用，不是 GPU 利用率。Chrome 内存占用空间也不等同于整机内存或 GPU 显存。

每阶段 60 秒，在第 40 秒和 60 秒截图
阶段操作主要观察
A · 基线关闭侧栏，不录制，保持作品动画运行。网页本身的 CPU / 内存与视觉流畅度。
B · 仅开侧栏打开侧栏，保持已连接，不标注、不录制。侧栏闲置增加多少占用，网页是否受影响。
C · 完整网页相同窗口与侧栏宽度，录制 60 秒。网页、映录、GPU Process 的变化及肉眼卡顿。
C 停止后停止，先不要预览；等待 30 秒再截图。采集与编码是否结束，CPU 是否回落，保存有无异常。
D · 框选区域固定选区并记下宽高，录制 60 秒。与 C 的差异；选区越小不必然越省资源。
D 停止后停止，先不要预览；等待 30 秒再截图。资源回落，停止是否及时，网页是否恢复操作。
如何避免误判

打开侧栏会改变网页可用宽度，因此 A / B 只能做粗略参考；B / C / D 务必固定视口。如果结果波动明显，交换 C / D 顺序再测 2–3 轮。内存不立即回到初始值不等于泄漏：看闲置和重复录制后是否持续上涨，并同时观察 CPU 是否停止繁忙。

基础对比发现问题后再补测

  1. 在 B / C / D 各做同一组动作：「选择画笔 → 连续长笔迹 → 切换文字并输入 → 清空 → 操作网页」。记下从哪一步开始卡顿。
  2. 只针对有问题的 C 或 D 再启用性能诊断。恢复后在录制库「性能诊断（仅本机）」下载 JSON，连同任务管理器截图一起保留。
  3. 需要区分 GPU 压力时，打开 Windows 任务管理器的 GPU 页面，记录 3D、Video Encode、Video Decode 与专用 / 共享 GPU 内存。不同设备不一定提供全部图表。
  4. 需要比较画质时，使用同一场景和目标画质，检查导出文件分辨率、编码、实际帧率、时长、大小。30 / 60 FPS 设置值不等于最终成片实际帧率。

扩展诊断中的网页帧回调不是 WebGL 渲染帧率；Canvas 提交次数也不是编码器实际输出帧数。诊断本身会带来额外工作，因此与基础测试分开。数据释义参考 Chrome 内存问题文档与 Windows GPU 任务管理器说明。

② 成片与交互验收

完成停止后的资源截图，再打开预览和导出，避免把回看、转码的开销混入录制数据。

对整页与区域分别检查
检查点执行方法通过条件
画面和效果记录一次切换镜头、天气或项目特效的时间点；对照网页与原片。效果完整；能区分现场卡顿、成片卡顿、播放器卡顿。
标注与工具排除画框、输入文字、插入参数图片；使用侧栏切换工具。网页标注进入视频，侧栏控制区不出现。编辑框和选中手柄进入视频属于当前设计。
选区稳定保持窗口、缩放、侧栏宽度不变；操作项目。固定区域持续录制，不误报尺寸变化；不要求重复框选。
真实视口变化另做短录，主动调整窗口或侧栏宽度。如果真实 CSS 视口改变，应停止并保存已有片段，明确提示重新框选。只改变采集容器像素大小可重新映射。
停止与恢复停止后操作网页，再点击「显示上次标注」。媒体释放、网页可操作，标注按原位置恢复。刷新会清空页内标注。
导出与 MP4先保存原片，再按运行时支持直接录 MP4 或转换 WebM。手动下载，文件可播放、音画时长合理；取消或失败不损坏原片。

声音与长视频另开一轮

基础性能通过后，再分别增加网页声音、麦克风、背景音乐，检查各路音量和同步。长视频需要实际录制来验证：分阶段记录保存体积、预览前后内存和停止后的回落；短视频补齐文件字节的合成测试只能证明大文件路径，不能证明长时解码性能。空间压力测试请使用专用浏览器配置和可丢弃数据。

如何扩展测试
新增性能路线时，先保留整页与区域的统一对照，再验证标注像素、音画同步、取消、资源释放和源视频保留；收益不足或限制过多时，不扩大功能范围。
